# ohtemizlik.com

OH Temizlik'in web sitesi. Statik HTML; GitHub Pages ile yayınlanır.

- Sayfalar `build.py` ile üretilir. Metin, hizmet ve ilçe listesi bu dosyadadır.
- Değişiklikten sonra: `python3 build.py`
- Stil: `assets/css/style.css`, betik: `assets/js/main.js`
- Yazı tipleri (Bricolage Grotesque, Figtree) SIL Open Font License ile `assets/fonts` içinde.
